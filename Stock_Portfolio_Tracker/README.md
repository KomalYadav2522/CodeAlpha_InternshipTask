# Stock Portfolio Tracker

A beginner-friendly Python application that helps users manage their stock investments and calculate portfolio performance.

## Features

- Add stocks with company name, symbol, quantity, and purchase price.
- View all stocks in the portfolio.
- Calculate total investment.
- Update current stock prices.
- Calculate individual stock profit or loss.
- Calculate overall portfolio profit or loss and percentage.
- Remove stocks from the portfolio.
- Automatically save portfolio data using JSON.

## Technologies Used

- Python
- JSON
- Visual Studio Code

## How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```

5. Follow the menu displayed in the terminal.

## Data Storage

Portfolio information is stored locally in a JSON file named `portfolio.json`.
